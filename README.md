# karthikashwa.exe — Personal Portfolio

Responsive portfolio for Ashwa Karthik focused on cybersecurity, Python, AI, automation, and electronics.

## Run locally
Open `index.html` in Safari, Chrome, or Firefox. No database or build tools are required.

## Customize
Edit the `SITE` object near the bottom of `index.html` to update your roles, skills, projects, certificates, and contact information.

Only publish project features and certificate verification URLs you can confirm. Add Instagram or other social profiles once you have their exact public URLs.
